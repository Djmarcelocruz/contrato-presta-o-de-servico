# Quick Start - DJ Brow

Guia rápido para começar a usar o DJ Brow em 5 minutos.

## 🚀 Acesso Rápido

1. **Acesse o sistema:** https://seu-dominio.manus.space
2. **Faça login** com sua conta Manus OAuth
3. **Comece a usar!**

## 📱 Instalação como App (PWA)

### iOS (iPhone/iPad)

1. Abra o Safari
2. Acesse https://seu-dominio.manus.space
3. Toque no ícone de compartilhamento (canto inferior)
4. Selecione "Adicionar à Tela de Início"
5. Confirme o nome e toque em "Adicionar"

### Android

1. Abra o Chrome ou navegador compatível
2. Acesse https://seu-dominio.manus.space
3. Toque no menu (3 pontos)
4. Selecione "Instalar aplicativo" ou "Adicionar à tela inicial"
5. Confirme a instalação

## 🎯 Fluxo Principal (Cliente → Orçamento → Contrato → Recibo)

### Passo 1: Criar um Cliente

1. No Dashboard, clique em **"NOVO CLIENTE"**
2. Preencha os dados:
   - Nome completo
   - Email
   - Telefone
   - CPF (opcional, criptografado)
   - Endereço, cidade, estado, CEP
3. Clique em **"Salvar"**

### Passo 2: Criar um Orçamento

1. Clique em **"Novo Orçamento"** ou vá para **Orçamentos**
2. Selecione o cliente criado
3. Escolha a data do evento
4. Selecione o tipo de evento (Casamento, Aniversário, etc.)
5. Clique em **"Criar"**

**Nota:** O sistema alertará automaticamente se houver conflito de datas.

### Passo 3: Gerar Contrato

1. Vá para **Contratos**
2. Clique em **"Novo Contrato"**
3. Selecione o orçamento criado
4. O contrato será pré-preenchido automaticamente
5. Revise e clique em **"Salvar"**

### Passo 4: Emitir Recibo

1. Vá para **Recibos**
2. Clique em **"Novo Recibo"**
3. Selecione o cliente e orçamento
4. Insira o valor recebido e forma de pagamento
5. Clique em **"Gerar Recibo"**

**O recibo será numerado automaticamente!**

## 💰 Gestão Financeira

### Registrar Entrada (Receita)

1. Vá para **Fluxo de Caixa**
2. Clique em **"Nova Entrada"**
3. Preencha:
   - Tipo: Entrada
   - Categoria: DJ (ou outra)
   - Valor
   - Data
   - Descrição
4. Clique em **"Salvar"**

### Registrar Saída (Despesa)

1. Vá para **Fluxo de Caixa**
2. Clique em **"Nova Saída"**
3. Preencha:
   - Tipo: Saída
   - Categoria: Manutenção, Combustível, etc.
   - Valor
   - Data
   - Descrição
4. Clique em **"Salvar"**

### Ver Resumo Financeiro

1. No **Dashboard**, você vê:
   - Receitas do mês
   - Despesas do mês
   - Lucro do mês
   - Eventos agendados

## 📦 Gestão de Estoque

### Adicionar Equipamento

1. Vá para **Estoque**
2. Clique em **"Novo Equipamento"**
3. Preencha:
   - Nome (ex: "Caixa de Som JBL 500W")
   - Descrição
   - Categoria (Som, Iluminação, Cabos, etc.)
   - Quantidade
   - Valor unitário
   - Quantidade mínima (para alertas)
4. Clique em **"Salvar"**

### Alertas de Estoque Baixo

O Dashboard mostra automaticamente equipamentos com estoque baixo. Configure a quantidade mínima ao criar o equipamento.

### Buscar Equipamento

1. Na página de **Estoque**
2. Use a barra de busca para encontrar por nome ou descrição
3. Filtre por categoria se necessário

## 📊 Relatórios

### Ver Relatórios Financeiros

1. Vá para **Relatórios**
2. Você verá:
   - Gráfico de ganhos mensais
   - Gráfico de ganhos por tipo de serviço
   - Métricas de desempenho
   - Ticket médio
   - Taxa de conversão

### Filtrar por Período

1. Nos **Relatórios**, selecione:
   - Data inicial
   - Data final
2. Os gráficos se atualizam automaticamente

## ⚙️ Configurações

### Acessar Configurações

1. Clique em **"Configurações"** (canto superior direito do Dashboard)
2. Você pode:
   - Editar seu perfil
   - Gerenciar notificações
   - Ver informações de segurança
   - Fazer logout

## 🔍 Dicas Úteis

### Busca Rápida

- **Clientes:** Busque por nome, telefone ou CPF
- **Estoque:** Busque por nome ou descrição
- **Orçamentos:** Filtre por cliente ou data

### Atalhos

- **Dashboard:** Ações rápidas para criar novo orçamento, cliente ou equipamento
- **Fluxo de Caixa:** Filtros por período para análise rápida
- **Relatórios:** Visualize tendências em tempo real

### Offline

O sistema funciona offline! Quando você voltar a ficar online, os dados serão sincronizados automaticamente.
